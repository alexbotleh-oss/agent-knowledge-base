# CARD — контекст проекта

CARD — веб-интерфейс хранения и использования скидочных карт: QR-коды, редактирование, восстановление данных и публикация через GitHub Pages.

## Риски
- Проверять отдельно сохранение карточек и восстановление/импорт.
- QR-коды отдельных сетей могут быть временными и истекать.
- Service worker может показывать кэшированную версию; проверять актуальность ресурсов и кэша.
- Изменения пропорций и типографики подтверждать визуальным сравнением.
- При изменении UI сохранять рабочие функции.

## Правило работы
Перед патчем изучить актуальный код и историю. Не считать старые SHA текущими без проверки. Зафиксировать baseline, сделать минимальный патч и проверить добавление, редактирование, сохранение, восстановление, QR и адаптивность.
