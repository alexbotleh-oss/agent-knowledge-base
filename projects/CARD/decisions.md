# CARD — решения

- Сохранение и восстановление — критические сценарии; изменения в них требуют отдельных проверок.
- Размеры карточек и расположение элементов подтверждать скриншотами, не только CSS.
- При диагностике GitHub Pages учитывать кэш service worker и не делать вывод о поломке по одному неудачному открытию.
- Сохранять совместимость с существующими данными и импортом/экспортом.
- Новые решения фиксировать с датой, причиной, доказательством и статусом проверки.
