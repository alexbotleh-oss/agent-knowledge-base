# DECISIONS — ORGANISM

## DEC-ORGANISM-001 — Полноценное приложение, а не только ChatGPT bridge
- **Дата:** 2026-10-08.
- **Статус:** принято пользователем.
- ORGANISM должен быть полноценным приложением непрерывного агента с собственной памятью, историей, импортом и Context Engine.
- Принятый путь: архитектура → PWA → телефонные тесты → исправления → полноценное приложение; агент обязателен.

## DEC-ORGANISM-002 — Первая платформа Android
- **Дата:** 2026-10-09, по доступной сводке.
- **Статус:** принято пользователем.
- Первая платформа — Android-телефон; интерфейс ИИ встраивается через WebView; автономность максимальная в заданных ограничениях.

## DEC-ORGANISM-003 — RAW и структурированная память разделены
- **Дата:** 2026-10-08.
- **Статус:** архитектурное требование.
- Сохранять первичный материал неизменённым и связывать его с извлечёнными объектами/выводами через provenance; не заменять RAW интерпретацией.
- Хранить источники, версии, конфликты, неопределённость, rejected paths и coverage/loss.

## DEC-ORGANISM-004 — Импорт должен быть доступен пользователю
- **Дата:** 2026-10-09.
- **Статус:** принятое требование.
- Успешный импорт не считается готовым, пока беседы нельзя просматривать, искать и управлять ими из приложения.

## DEC-ORGANISM-005 — CI/build не равен device PASS
- **Дата:** 2026-10-10.
- **Статус:** обязательное правило отчётности.
- Разделять syntax, build, install, device runtime, UI interaction, network/OAuth и persistence. Не утверждать исправление WebView по успешному CI.
