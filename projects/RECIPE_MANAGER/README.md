# RECIPE_MANAGER memory package

Эта директория сохраняет проектную память «Что приготовить» / Recipe Manager отдельно от общей памяти агента.

## Файлы
- context.md — цель, область, требования и ограничения.
- PROJECT_STATE.md — текущий снимок состояния и неопределённости.
- TASK_STATE.md — состояние переноса памяти в knowledge base.
- EVENT_LOG.md — хронология инцидентов, решений и результатов.
- DECISIONS.md — требования и решения пользователя.
- LESSONS.md — положительный и отрицательный опыт со статусами.
- HANDOFF.md — точка продолжения следующей сессии.

## Источники и полнота
Восстановлено по доступной истории текущего чата, контекстным сводкам проекта и именам/фрагментам вложений, имеющимся в этой сессии. Это не полный экспорт всех старых чатов. Отсутствующие доказательства и неподтверждённые исправления явно отмечены; записи не следует читать как подтверждение текущей работоспособности приложения.

## Ключевое ограничение
Если следующая задача относится к коду приложения, сначала сверить текущий файл/ветку и репродуцировать проблему. Этот пакет сам по себе не доказывает, что заявленные ранее исправления были протестированы.
