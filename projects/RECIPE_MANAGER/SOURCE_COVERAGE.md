# RECIPE_MANAGER — охват источников и пробелы переноса

## Доступность источников
- **A — прочитано в текущем контексте:** README и протоколы agent-knowledge-base, templates, validator, CI workflow; пользовательские `diagnostics_probe2 (1).json` и `diagnostics_probe3.json`.
- **B — сведения есть в сохранённой сводке, исходник здесь не перечитан:** часть build logs, diagnostics_probe1.json, прежняя диагностика после JNI FIX1, исторические ZIP и версии исходников.
- **C — упомянуты в старых сообщениях, полное содержание недоступно:** `Что приготовить*.htm/html`, `index_db_path*.html`, `recipes*.db`, `recipe_manager_foodru*.py`, часть скриншотов, полные tracebacks и полная необработанная выгрузка чата.

## Перенесено
- Требования импорта/нормализации, КБЖУ, рецептов и покупок — DECISIONS.md.
- Сообщённые регрессии, Flet API error и профилактические уроки — DECISIONS.md, LESSONS.md.
- Core Lite baseline hashes, diagnostics path, границы py_compile, JNI conflict/fix1 build, невалидный PROBE1 и наблюдения PROBE2/PROBE3 — EVENT_LOG.md.
- Состояние и точка продолжения — PROJECT_STATE.md, TASK_STATE.md, HANDOFF.md.

## Пробелы
1. Полная выгрузка чата недоступна; это перенос всего материала, доступного сейчас, а не гарантированно полная архивная миграция.
2. Исторические HTML/DB/PY/ZIP не загружались в текущей задаче и не перепроверялись по байтам; они могут дополнить хронологию и diff.
3. Причина белого экрана неизвестна. Подтверждены GRANTED, создание WebView, page.update и логирование вызова load_html; фактический рендер не подтверждён.
4. Причина отсутствия marker events PROBE3 неизвестна. Несоответствие исходника/сборки/APK — гипотеза.
5. Импорт Food.ru/1000.menu, нормализация и КБЖУ не перепроверялись на актуальном коде.
6. При появлении новых вложений добавлять недостающее, не дублировать смыслы и не переписывать append-only события без отметки.
