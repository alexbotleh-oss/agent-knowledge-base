# LESSONS — AGENT_MEMORY_SYSTEM

## L-AGMS-20261013-001 — Сверяй PR-описание с живыми метаданными и CI на точном SHA

- **Статус:** candidate; наблюдение подтверждено, первопричина расхождения не установлена.
- **Источник:** PR [#22](https://github.com/alexbotleh-oss/agent-knowledge-base/pull/22), baseline commit [f879e9c6ba4ae7931d31ae3f6ef043320785b1b0](https://github.com/alexbotleh-oss/agent-knowledge-base/commit/f879e9c6ba4ae7931d31ae3f6ef043320785b1b0), CI run [#38382449482](https://github.com/alexbotleh-oss/agent-knowledge-base/actions/runs/38382449482).
- **Наблюдаемая проблема:** описание PR отставало от фактических метаданных GitHub по HEAD и количеству изменённых путей.
- **Причина:** unknown; нельзя заключать, что описание не обновлялось намеренно или что CI был запущен неправильно.
- **Неудачный подход:** принимать цифры и статус из тела PR за актуальный источник истины.
- **Эффективный подход:** получить PR metadata, точный head SHA, changed-file list/compare и workflow run, связанный с этим SHA; после новых коммитов повторить проверку.
- **Правило предотвращения:** любое заявление о текущем HEAD, количестве файлов или CI должно сопровождаться свежей проверкой и точной ссылкой; PASS не переносится с одного SHA на другой.
- **Применимость:** GitHub PR и любые задачи с асинхронными CI-проверками.
