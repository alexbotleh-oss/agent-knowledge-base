# Реестр отложенной сверки архива и сохранения опыта

Дата фиксации: 2026-10-14

## Принятое рабочее решение

Не повторять массовую выгрузку чатов ради объединения уже накопленного опыта. Сначала использовать доступные записи и архивный срез, затем отделить непроверенное/позднее для последующей сверки при поступлении новых архивов. Подтверждённое объединять и продолжать развитие системы памяти.

## Статусы сверки

- `CONFIRMED_PRE_ARCHIVE` — вывод подтверждён доступными первичными свидетельствами в пределах проверенного временного среза.
- `SUPPORTED_PARTIAL` — часть вывода подтверждена; ограничения явно записаны.
- `PENDING_ARCHIVE_MATCH` — исходный материал пока не найден в доступной выгрузке; сохранить текущую запись и происхождение, сверить при следующем архиве.
- `POST_ARCHIVE` — событие относится к периоду после границы архивного среза; не считать его отсутствующим только потому, что его нет в старом архиве.
- `CONFLICT` — источники расходятся; сохранить обе версии и основания, не перезаписывать одну другой.
- `DUPLICATE_CANDIDATE` — возможный повтор/копия; не удалять, пока не подтверждена эквивалентность и сохранность происхождения.

## Правило сохранности

До принятия решений об объединении/удалении:
1. Сверить актуальный HEAD, базу сравнения и CI.
2. Проверить, есть ли материал в `main`, PR #22, архивной/резервной ветке и исходных документах.
3. Для каждого материала сохранить путь, исходный источник, временную границу, статус проверки и связи с другими записями.
4. Всё, что пока не удалось подтвердить, оставить доступным в отдельной ветке и пометить для будущей сверки.
5. Не удалять единственную копию и не считать отсутствие в архиве доказательством отсутствия события.
6. После сверки объединять только ту часть, для которой установлены содержание, происхождение и границы применимости.

## Ограничение доказательств

Успешный CI подтверждает только выполненные автоматические проверки на конкретном commit. Он сам по себе не доказывает полноту истории, правильность семантического объединения или наличие всех исходных вложений.
