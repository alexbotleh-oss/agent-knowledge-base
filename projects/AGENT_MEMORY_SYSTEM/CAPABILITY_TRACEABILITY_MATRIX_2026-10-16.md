# Capability traceability matrix — 2026-10-16

**Purpose:** one place to answer, for each planned agent capability, which specification owns it, which implementation exists, which tests/evidence support its status, what branch contains it, and what is still missing. This matrix is revision-scoped; it must be updated when implementation or acceptance evidence changes.

## Status vocabulary

- **VERIFIED_SYNTHETIC** — an end-to-end path passed with synthetic fixtures; production inputs/runtime remain unaccepted.
- **IMPLEMENTED_PARTIAL** — executable component and tests exist, but a required integration, data coverage, trust boundary or acceptance condition remains open.
- **SEPARATE_DRAFT** — implementation exists in a separate unmerged PR and is not part of the integration branch.
- **SPEC_ONLY** — documented design/protocol without a verified executable implementation of the full capability.
- **PROTOTYPE_NOT_ACCEPTED** — prototype exists, but the intended real environment has not passed acceptance.
- **BLOCKED** — no runtime mechanism satisfying the stated capability has been demonstrated.
