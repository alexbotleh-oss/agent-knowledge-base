- Secondary report is not independent corroboration when copied from another report.
- Open means evidence or destination reconciliation remains incomplete; do not silently promote to resolved.
- A gap can be closed only with a source locator, an explicit destination, a read-back/validation result, and an honest statement of remaining limits.
