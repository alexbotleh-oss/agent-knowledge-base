# LESSONS — CARD111

## L-CARD111-001 — Сохраняй коды и пользовательские карты при UI-работе
- **Источник:** EVT-CARD111-20261006-001/002.
- **Наблюдение:** пользователь явно исключил QR, штрихкоды, сканер и хранение из ряда визуальных задач.
- **Правило:** ограничивать diff согласованной областью; проверять сохранение существующих карт и данных после UI-изменений.
- **Статус:** validated as user constraint; конкретные будущие изменения требуют своих тестов.

## L-CARD111-002 — Статическая проверка не доказывает работу на телефоне и публикацию
- **Источник:** EVT-CARD111-20261006-002, EVT-CARD111-20261010-001.
- **Наблюдение:** статические проверки упоминались, но Pages мог показывать старый UI, а scanner/gallery/crop и device behavior оставались непроверенными.
- **Правило:** отдельно проверять source, deployment source/commit, live URL, device runtime и ключевые интеракции.
- **Статус:** candidate/medium; точная причина старой публикации неизвестна.

## L-CARD111-003 — Проверяй интерактивные пути отдельно и вместе с регрессией
- **Источник:** EVT-CARD111-20261010-002.
- **Наблюдение:** scanner, gallery import и crop positioning сообщены как разные сломанные сценарии.
- **Правило:** воспроизводить каждый путь, локализовать обработчик/состояние/рендер, после фикса проверять остальные сценарии и сохранение карты.
- **Статус:** candidate/medium; root causes не установлены.

## L-CARD111-004 — Каталог брендов — требование, не доказательство реализации
- **Источник:** EVT-CARD111-20261010-003.
- **Правило:** проверять фактический каталог и добавление шаблонов против полного списка в HANDOFF.md; не объявлять готовность по названию ветки/коммита.
- **Статус:** candidate; интеграция не подтверждена.
