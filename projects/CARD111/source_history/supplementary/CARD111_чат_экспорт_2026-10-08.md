# Ключевое требование предпросмотра

Пользователь:
«в оформлении эскиз карты уходить не должен, мы изменяем и хотим видеть как будет»

Следовательно, предпросмотр должен оставаться видимым при изменении оформления и обновляться сразу.

Используются:
- `editorPreviewData(c)`
- `refreshEditorPreview(c)`
- `bindEditorPreview(c)`
- `refreshEditorCodePreview(c)`

CSS содержит:
`.editorPreviewWrap { ... position: sticky; ... }`

# Визуальные проблемы, которые уже исправлялись

В истории CARD111 были:
- исчезновение карт после частичного изменения `index.html`;
- регрессии добавления;
- неправильные пропорции;
- лишние элементы;
- изменения нижней навигации;
- проблемы кеша GitHub Pages/service worker.

Поэтому:
**изменение кода ≠ опубликованный результат ≠ подтверждённый результат на телефоне.**

# Service Worker

Регистрация:
```javascript
navigator.serviceWorker.register("sw.js?v=50")
```

Из-за кеширования телефон может показывать старую версию даже после изменения GitHub Pages.
