# CARD111 — исходная история и индекс источников

Этот каталог хранит **извлечённые исходные объекты диалогов CARD111**, индекс сообщений, индекс вложений и отдельные явно обозначенные вторичные материалы. Он не заменяет первоисточники пересказом и не утверждает, что вся история CARD111 когда-либо созданных чатов уже найдена.

## Первичный экспорт

Исходный архив находится в пользовательской Library: `/conversations.zip`.

- SHA-256 архива: `df7ffbe9a2ffcad27b5367af90d69c5cb38f17d61bb9f7a5207484e0343db956`
- Внутри один файл: `conversations.json`, 42,997,976 байт.
- В этом снимке 37 conversation objects.
- Манифест: `/export_manifest.json`, SHA-256 `2a945f37a333...` (полный SHA и количество записей — в `source_index.json`).
- Карта имён вложений: `/conversation_asset_file_names.json`, 876 записей.

Полный account-wide ZIP и полный манифест **не скопированы** в публичный репозиторий: в них есть истории других проектов. Вместо этого сюда перенесены шесть выбранных объектов диалогов, сохранив их внутренние структуры, message IDs, timestamps, порядок узлов, связи `parent` и метаданные вложений. JSON отформатирован для чтения; содержимое сообщений и mapping не редактировались.

### Индексы

- [`source_index.json`](source_index.json) — SHA-256 источников, границы покрытия, счётчики и перечень дополнительных источников.
- [`message_index.jsonl`](message_index.jsonl) — одна запись на сообщение: UTC timestamp, role, message ID, node ID, parent node ID, recipient/channel и имена вложений.
- [`attachment_index.jsonl`](attachment_index.jsonl) — attachment ID, исходное имя, тип, размер, conversation/message IDs и сопоставленное имя из asset map.
- [`attachment_availability.json`](attachment_availability.json) — сверка 150 уникальных attachment IDs с текущей Library: точное совпадение по ID, совпадение только по имени или отсутствие.

**Как найти сообщение:** ищи точный `message_id` в `message_index.jsonl`; возьми `conversation_id` и `node_id`; открой соответствующий JSON в `raw/conversations/` и найди узел `mapping[node_id]` / поле `message.id`. Для временного поиска фильтруй индекс по ISO-метке UTC. Для вложения ищи его ID или имя в `attachment_index.jsonl`, затем переходи по указанным conversation/message IDs.

## Вложения: что действительно скопировано

- Пять текстовых source attachments сохранены в репозитории: первоначальное предложение проекта, состояние передачи от 5 октября, запрос полного извлечения чата (эксперимент №3), запрос переноса памяти (эксперимент №4) и отчёт о состоянии/регрессии от 6 октября.
- Ещё три вторичных материала от 8 октября сохранены отдельно: короткий диалог, частичный экспорт чата и сводка визуальных требований.
- Все 150 уникальных attachment IDs из выбранных диалогов точно сопоставлены с записями текущей Library по ID. **Это не означает, что все бинарные вложения скопированы в GitHub.** Остальные 145 payloads оставлены в Library и перечислены в `attachment_availability.json`; это главным образом изображения/скриншоты, HTML, PDF и версии CORE.
- Бинарные вложения в `conversations.zip` отсутствуют: там только сообщения и metadata. Не связанные с CARD111 вложения (например, RecipeManager ZIP) не копируются в CARD111-подкаталог.
- Диагностический файл с user-agent/device metadata не публиковался в этом каталоге; он остаётся в Library и должен пройти отдельную проверку приватности, если потребуется копирование.

## Ограничения и безопасность

- Не объявлять историю полной до сверки с другими доступными чатами/экспортами и продолжением после 2026-10-08.
- Не путать требования и заявления ассистента с подтверждённой реализацией. По CARD111 остаются неподтверждёнными deployment, scanner, gallery import, crop repositioning, QR/barcode readability и сохранность существующих карт на реальном устройстве.
- Не считать упомянутые короткие SHA подтверждением полного diff; сверять исходный репозиторий приложения `alexbotleh-oss/CARD`.
- Общая память агента должна получать только универсальные уроки извлечения/проверки источников, а не полную историю CARD111.
