# Общие переносимые уроки

Эти уроки извлечены из контекста RECIPE_MANAGER и сохранены с указанием происхождения. Они не заменяют проектные требования и перед применением требуют проверки совпадения технологий и условий.

## G-LESSON-001 — Разделяй этапы проверки и сообщай только доказанное
- **Источник:** RECIPE_MANAGER, EVT-20261012-002; сохранённая сводка о Python `py_compile` и незавершённой Android-отладке.
- **Наблюдение:** синтаксический тест Python не доказывает, что упаковка, установка и запуск приложения на целевом устройстве работают.
- **Правило:** сообщать PASS по каждому этапу отдельно: syntax/lint → build/package → install → runtime → visual interaction → regression. Использовать SKIP/BLOCKED, когда проверка фактически не выполнялась.
- **Подтверждение:** применима логика разных этапов проверки; в данном проекте факт текущего Android runtime не подтверждён.
- **Применимость:** любые приложения с раздельными этапами компиляции, упаковки и выполнения.
- **Ограничения:** единичный проект не доказывает качество всех возможных тест-стратегий; урок — точность отчётности, не конкретный рецепт сборки.

## G-LESSON-002 — Перед исправлением ошибки конструктора проверить фактическую версию API
- **Источник:** RECIPE_MANAGER, EVT-20260927-001; ошибка `PopupMenuItem.__init__() got an unexpected keyword argument 'text'`.
- **Наблюдение:** runtime отверг аргумент конструктора.
- **Вероятная причина:** несоответствие аргумента фактическому API установленной версии; конечная версия и patch не восстановлены.
- **Правило:** сверить установленную версию и сигнатуру API; избегать механического переноса параметров между версиями; подтвердить фикс runtime-тестом.
- **Статус:** candidate/medium — симптом подтверждён, причина в точности версии и окончательное исправление не доказаны доступными данными.
- **Применимость:** библиотеки, чьи публичные API меняются между версиями.
- **Ограничения:** не объявлять эту конкретную гипотезу причиной любой ошибки Flet без нового traceback.

## G-LESSON-003 — Перед упаковкой сверять комплект исходников и ресурсов
- **Источник:** RECIPE_MANAGER, EVT-20261012-002; сводка указывает, что после возвращения `seed_data.py` `flet run main.py` стал работать.
- **Наблюдение:** состав рабочего каталога влиял на запуск в описанной ситуации.
- **Правило:** перед переносом между машинами или упаковкой сверить модули/данные/иконки/конфигурацию; не заменять каталог частичным ZIP без понимания его состава.
- **Статус:** candidate/medium — наблюдение по сводке, без полного trace и независимо повторённого воспроизведения.
- **Применимость:** Python-проекты с локальными модулями и ресурсами; другие стеки — только по аналогии.
- **Ограничения:** отсутствие конкретного файла не считать причиной нового дефекта без доказательства.

## G-LESSON-004 — Проверяй реальное состояние данных после CRUD/импорта
- **Источник:** RECIPE_MANAGER, EVT-20260922-001; пользователь сообщал о непополнении списка рецептов и исчезновении функций удаления/КБЖУ после изменений HTML-проекта.
- **Наблюдение:** отсутствие явной ошибки не доказывает сохранение или отображение данных.
- **Правило:** после CRUD/импорта проверять фактическую запись и повторное чтение, а для UI — видимость, пустое состояние, удаление и смежные поля.
- **Статус:** validated как процедурная предосторожность; конкретная причинная связь между всеми историческими регрессиями не установлена.
- **Применимость:** формы, локальные БД, импорт/экспорт, CRUD UI.
- **Ограничения:** HTML-инциденты нельзя напрямую приписывать Android-коду без доказательства.
