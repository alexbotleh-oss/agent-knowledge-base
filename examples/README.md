# Реальные обучающие кейсы

Сюда добавляются только кейсы, извлечённые из настоящих проектов и подтверждённые доступными источниками. Не заполнять каталог вымышленными историями ради количества.

Для каждого кейса хранить:
- краткий контекст и намерение пользователя;
- фактическую последовательность ключевых событий;
- успешные решения и неудачные попытки;
- что известно о причине и что остаётся гипотезой;
- ссылки на исходный чат/файл/коммит/тест;
- переносимый урок и условия применимости;
- способ проверить, что агент применяет урок в новом чате.

Не копировать большие фрагменты переписок без необходимости. Сохранять происхождение, важные причинные связи и факты, необходимые для повторного использования. Удалять секреты и ненужные персональные данные. Различать подтверждённые и предварительные кейсы.
